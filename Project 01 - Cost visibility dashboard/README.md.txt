# Project 1 - Azure Cost Visibility Dashboard

## Scenario

BrightPath Solutions required greater visibility into Azure spending across its cloud environment.

As a Junior Cloud Administrator, I was tasked with implementing a cost monitoring solution that would provide insights into Azure consumption, identify spending trends, and support cost optimisation efforts.

## Project Objectives

- Analyse Azure costs
- Monitor resource consumption
- Identify spending trends
- Improve cost visibility
- Create management reporting

## Technologies Used

- Azure Cost Management
- Azure Monitor
- Azure Resource Groups
- Azure Dashboards

## Skills Demonstrated

- Cost Management
- Azure Administration (AZ-104)
- Monitoring and Reporting
- Cloud Governance
- Documentation
